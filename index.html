01 WriteFlow AI 서비스 개요

1인 크리에이터가 정보·지식형 콘텐츠 원고를 쉽고 빠르게 만들 수 있도록 돕는 AI 서비스.

서비스 정의

  • 정보·지식형 콘텐츠를 제작하는 1인 크리에이터를 위한 AI 콘텐츠 원고 제작 서비스
  • 사용자가 콘텐츠 주제나 참고자료를 입력하고 콘텐츠 종류·목적·스타일·길이를 선택하면 Blog 글, YouTube 대본, Shorts 대본을 자동 생성
  • 복잡한 프롬프트 작성 대신 선택형 인터페이스를 제공하여 초보 크리에이터도 쉽게 사용 가능

프로젝트 목표

  • 1인 크리에이터가 주제나 자료 입력 후 1분 이내에 수정하여 활용할 수 있는 콘텐츠 초안 확보
  • 초기 MVP는 원고 작성에 소요되는 반복 업무를 줄이는 것에 집중

02 추진 배경 및 문제 정의

1인 크리에이터는 콘텐츠 제작의 모든 과정을 혼자 수행하며, 특히 원고 작성 과정에서 많은 어려움을 겪는다.

1인 크리에이터의 어려움

  • 콘텐츠 제작 전 과정 수행 — 경제·주식, AI·IT, 뉴스, 생활정보 등 정보·지식형 콘텐츠 제작자는 기획부터 자료 정리, 원고 작성, 촬영·편집까지 대부분을 혼자 수행
  • 원고 작성의 복잡성 — 같은 소재라도 Blog는 정보형 글, YouTube는 말하기 자연스러운 대본, Shorts는 압축된 대본이 각각 필요

기존 생성형 AI 활용의 한계

  • 복잡한 프롬프트 작성 — 매번 "5분짜리 YouTube 대본으로 작성해줘" 같은 조건을 직접 작성해야 함
  • 반복적인 수정 과정 — 원하는 결과가 안 나오면 조건을 다시 설명하며 여러 번 수정 필요, 초보자에게는 프롬프트 작성 자체가 또 다른 작업
WriteFlow AI의 해결 방안 — 복잡한 프롬프트 작성 과정을 간단한 선택형 UI로 전환하여, 크리에이터가 원고 작성 시간을 줄이고 콘텐츠 기획·제작에 집중할 수 있도록 지원한다.

03 주요 타깃 사용자

정보·지식형 콘텐츠를 제작하는 초보·소규모 1인 크리에이터 및 예비 크리에이터를 핵심 사용자로 설정.

정보·지식형 콘텐츠 크리에이터

경제·주식, AI·IT, 뉴스·시사, 생활정보 등을 혼자 제작하는 초보·소규모 1인 크리에이터 및 예비 크리에이터

원고 작성에 어려움을 겪는 사용자

아이디어·자료는 있지만 원고 정리 시간이 오래 걸리고, 생성형 AI 경험은 있으나 복잡한 프롬프트에 익숙하지 않은 사람

다양한 플랫폼 활용 사용자

전문 인력 없이 기획·제작을 혼자 수행하며, 하나의 소재를 Blog·YouTube·Shorts 등 여러 플랫폼에서 활용하고 싶은 사용자

향후 확장 방향

초기엔 핵심 사용자층에 집중해 서비스를 검증하고, 이후 소규모 사업자·마케팅 담당자·기업 콘텐츠 운영 조직으로 확대

04 서비스 이용 방식

사용자가 긴 프롬프트 없이 몇 가지 항목 선택만으로 콘텐츠 초안을 만들 수 있도록 단순하게 구성.

단계설명
1. 주제/자료 입력콘텐츠로 만들고 싶은 주제나 참고자료를 입력
2. 콘텐츠 종류 선택Blog / YouTube / Shorts 중 원하는 콘텐츠 유형 선택
3. 콘텐츠 목적 선택정보 전달 / 이슈 설명 / 분석 / 흥미 유발 중 선택
4. 스타일 선택쉽게 / 전문적 / 친근하게 / 재미있게 중 선택
5. 길이 선택콘텐츠의 길이 설정
6. AI 원고 생성선택한 조건에 맞춰 AI가 원고를 생성
7. 수정 및 활용생성된 원고를 수정·복사하여 콘텐츠 제작에 활용

05 MVP 주요 기능

사용자가 콘텐츠 초안을 효율적으로 생성하고 수정할 수 있도록 다양한 기능을 제공.

콘텐츠 입력 및 유형 지원

분류세부 기능설명
콘텐츠 입력주제/참고자료 입력메모, 뉴스, 조사자료, 인터뷰, 강의자료, 기존 초안 등을 입력
콘텐츠 유형 지원Blog제목, 도입부, 소제목, 본문, 정리 등 읽기 좋은 정보형 글 생성
YouTube제목·Hook·오프닝·본문·마무리 등 말하기 자연스러운 대본 생성
Shorts약 30~60초 안에 전달되는 Hook·핵심 내용·결론 중심 구성
제목·Hook 후보제목/Hook 후보 제공YouTube·Shorts는 제목과 Hook 후보를 각 3개 제공, 사용자가 선택

원고 수정 및 관리 기능

분류세부 기능설명
원고 수정빠른 수정 기능"더 짧게, 더 길게, 더 쉽게, 더 재미있게, 다시 생성" 등 즉시 편집
원고 관리버전 비교 및 저장최근 3~5개 생성 결과를 임시 저장해 이전 버전과 비교
전체 복사 기능완성된 원고를 전체 복사해 다른 제작 도구에서 바로 사용

07 생성 품질 및 정확성 관리

기능의 수보다 실제로 사용할 수 있는 원고를 안정적으로 생성하는 것을 핵심 경쟁력으로 삼으며, 정확성 관리에 중점.

  • 참고자료 우선 활용 — 사용자가 입력한 자료를 우선 활용하고, 자료에 없는 정보는 임의로 추가하지 않음
  • 정확성 안내 및 검증 — AI 생성 초안임을 명시하고 게시 전 사실관계 확인을 안내, 개발 과정에서 플랫폼 적합성·길이·말투·가독성·사실성·활용 가능성을 반복 검증
  • 사용자 피드백 활용 — 결과 화면에 👍/👎 평가 기능을 제공해 만족도를 확인하고 AI 프롬프트 개선에 반영

08 MVP 개발 범위 및 성공 기준

핵심 원고 생성 기능에 집중하며, 1인 크리에이터가 1분 안에 활용 가능한 초안을 얻을 수 있는지를 성공 기준으로 삼는다.

구현 기능

주제·참고자료 입력, Blog·YouTube·Shorts 선택, 목적·스타일·길이 설정, AI 원고 생성, 제목·Hook 추천, 빠른 수정, 복사, 최근 결과 임시 저장, 생성 진행 상태, 사용자 평가

제외 기능

회원가입, 결제, 뉴스 자동 수집, 실시간 트렌드 검색, 이미지·썸네일 생성, TTS, 영상 제작, YouTube 자동 게시 및 수익 분석

핵심 성공 기준

"1인 크리에이터가 주제나 자료를 입력하고 1분 안에 실제 콘텐츠 제작에 활용할 수 있는 초안을 얻을 수 있는가?"

평가 지표

생성 성공률 사용자 만족도 재생성률 실제 초안 활용 가능성

09 기술 구현 구조

WriteFlow AI MVP는 사용자가 입력한 주제와 선택 옵션을 기반으로 동적 프롬프트를 생성하고, AI API를 호출하여 플랫폼별 콘텐츠 결과를 반환하는 구조로 개발한다.

사용자가 선택한 콘텐츠 종류 · 목적 · 스타일 · 길이 값을 하나의 Prompt Engine에서 조합하여 AI 요청을 생성한다.

예시 설정
콘텐츠 유형: YouTube · 목적: 이슈 설명 · 스타일: 친근하게 · 길이: 5분

이 설정을 바탕으로 시스템이 내부적으로 플랫폼에 맞는 프롬프트를 자동 생성한다.

"입력 자료를 기반으로 YouTube용 약 5분 분량의 대본을 작성한다. 목적은 이슈 설명이며, 친근하고 이해하기 쉬운 스타일로 작성한다."

출력 구조 — 제목 후보 3개 · Hook 후보 3개 · 오프닝 · 본문 · 핵심 설명 · 마무리

수십 개의 프롬프트를 따로 관리하는 대신 사용자의 선택값을 조합하는 "Dynamic Prompt Engine" 방식으로 구현한다.

10 데이터 및 보안 설계

WriteFlow AI는 초기 MVP 단계에서 사용자의 콘텐츠 설정과 최근 생성 결과를 브라우저 내 임시 저장 방식으로 관리한다.

🗂️ Local Storage

최근 생성 결과와 기본 설정은 MVP 단계에서 브라우저 내 임시 저장

🔑 API Key Protection

OpenAI API Key는 Frontend 코드에 노출하지 않고 Backend 환경변수에서 관리

📎 Reference Data

사용자가 입력한 자료는 콘텐츠 생성 목적에 우선 활용하며 별도 사용하지 않는 것을 기본 원칙으로 설정

👥 Future Account System

향후 회원 기능 도입 시 사용자별 데이터 저장 및 접근 권한 구조 추가

11 기대 효과 및 차별화 방향

크리에이터의 원고 작성 시간을 줄여 콘텐츠 기획·제작에 집중하게 하고, 워크플로우 중심의 차별화된 서비스를 제공.

기대 효과

  • 반복적인 프롬프트 작성과 원고 초안 제작에 사용하는 시간을 절감
  • 콘텐츠 방향 결정·검토·실제 제작에 더 많은 시간 투자 가능

차별화 방향

  • 콘텐츠 제작 워크플로우 중심 서비스 — 프롬프트를 직접 설계하지 않고 종류 → 목적 → 스타일 → 길이 선택만으로 플랫폼에 맞는 결과 생성
  • One Source → Multi Content — 하나의 뉴스·자료·아이디어를 Blog·YouTube·Shorts로 동시에 변환

12 향후 확장 방향

1차 MVP에서 원고 생성 기능의 실효성을 확인한 후, 기능을 단계적으로 확장하여 AI Content Workspace로 발전하는 것을 목표로 한다.
